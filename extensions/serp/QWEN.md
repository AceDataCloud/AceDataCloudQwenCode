# Google Search by Ace Data Cloud

Web, image, and news queries consume search credits. Use the supported search types and country/language tools to prepare a query, then send it once. Start with `serp_list_search_types` for local information. For API access, users can [manage their application keys](https://platform.acedata.cloud/console/applications?utm_source=qwen-code&utm_medium=referral&utm_campaign=evergreen). Keep keys in the operating-system environment and out of chat.
