# Fish Audio

Speech synthesis consumes credits. Use a voice you have permission to use. Keep the returned task ID and use the same ID when checking progress. Start with `fish_get_usage_guide` for local information. For API access, users can [manage their application keys](https://platform.acedata.cloud/console/applications?utm_source=qwen-code&utm_medium=referral&utm_campaign=evergreen). Keep keys in the operating-system environment and out of chat.
