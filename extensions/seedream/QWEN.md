# Seedream

Image generation and editing consume credits. Keep the task ID returned by a submission. Use the task lookup on that same ID to retrieve its result; a pending job does not require another generation. Start with `seedream_list_models` for local information. For API access, users can [manage their application keys](https://platform.acedata.cloud/console/applications?utm_source=qwen-code&utm_medium=referral&utm_campaign=evergreen). Keep keys in the operating-system environment and out of chat.
